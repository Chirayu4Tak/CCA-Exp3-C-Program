# CCA Experiment 3 – C Program on Ubuntu

## Aim
To implement and run a C program on Ubuntu OS using VirtualBox.

## AI Use Case – Agriculture
The program demonstrates a simple water-stress calculation using sample soil-moisture and rainfall values. This represents basic edge-level analytics that can support an irrigation system.

## Program
The C program uses sample values for soil moisture and rainfall and calculates a simple water-stress index.

## Tools Used
- Ubuntu OS
- VirtualBox
- GCC Compiler
- C Programming Language

## Result
The C program was successfully compiled and executed. The calculated water-stress value was obtained successfully.
